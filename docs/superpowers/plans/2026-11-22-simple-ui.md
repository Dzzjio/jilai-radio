# Simple UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home page becomes a full-screen looping video with only a play/pause button, one lorem ipsum paragraph and the live listener count on top.

**Architecture:** `app/page.tsx` is rewritten to render a fixed `<video>` background plus a new client `SimplePlayer`. Media Session wiring moves out of `PlayerPanel` into a shared hook. Old components stay in the repo, unused.

**Tech Stack:** Next.js 16 (static page), React 19, CSS modules, ffmpeg for assets.

**Spec:** `docs/superpowers/specs/2026-11-22-simple-ui-design.md`

## Global Constraints
- No git commits (user rule). Give the user a one-line commit command at the end.
- Work in `apps/web`; branch `simple-ui`.
- Page stays `export const dynamic = "force-static"`.
- Video: `autoPlay muted loop playsInline`, `object-fit: cover`, `position: fixed; inset: 0`, sized with `100dvh` (fallback `100vh`).
- `prefers-reduced-motion: reduce` → video paused on its poster.
- Visible text is only: lorem ipsum paragraph + listener count. Invisible `<h1>` "Radio Aha" (class `sr-only`).

## Review Focus
- Portrait phone (390×844): video covers the whole screen, no bars top/bottom, no horizontal scroll.
- iOS Safari: video autoplays inline (needs `muted` + `playsInline`), not fullscreen.
- Listener count before data arrives: shows `—`, layout doesn't jump.
- Light and dark system theme: text readable over the light-grey fog (scrim + white text in both).
- Stream error: button returns to play icon; screen-reader `role="status"` still announces the error.
